1. PRÉSENTATION DU PROJET


1.1 Contexte

MxC Formations est une plateforme éducative numérique destinée à centraliser,

distribuer et suivre des applications pédagogiques gamifiées à destination

des étudiants de l'enseignement supérieur.


La plateforme s'adresse à un double public :

  • Les **professeurs / formateurs** qui créent et administrent les jeux
  • Les **étudiants** qui jouent et progressent

    • 1.2 Genèse

    La plateforme est née du développement de "Legal Quest", un business game

    sur le droit de l'internet et du e-commerce (UC D51.2 — Mastère E-Business).

    L'objectif est d'étendre ce modèle à toutes les matières enseignées.


    1.3 Objectifs pédagogiques

  • Consolider les acquis du cours par le jeu (learning by doing)
  • Favoriser l'engagement et la motivation des étudiants
  • Permettre au professeur de mesurer la compréhension en temps réel
  • Créer un outil réutilisable et évolutif par matière


    • 2. DESCRIPTION FONCTIONNELLE


    2.1 Architecture générale


    La plateforme se compose de TROIS espaces distincts :


    MxC FORMATIONS PLATFORM
│
├── ESPACE ÉTUDIANT (app mobile + web)
│   ├── Catalogue des jeux disponibles
│   ├── Connexion par code de promo/session
│   ├── Jeu en solo ou en équipe
│   ├── Tableau de bord personnel
│   └── Badges et classements
│
├── ESPACE PROFESSEUR (web)  
│   ├── Dashboard de suivi
│   ├── Création et gestion des jeux

│   ├── Statistiques détaillées
│   └── Export des résultats
│
└── BACK-END (Firebase)
    ├── Base de données (Firestore)
    ├── Authentification
    └── Stockage des médias


    3. FONCTIONNALITÉS DÉTAILLÉES


    3.1 ESPACE ÉTUDIANT


    3.1.1 Connexion & Profil

  • ☐ Connexion par prénom + nom + code de promo (ex: MEBB2025)
  • ☐ Pas de mot de passe (friction minimale)
  • ☐ Profil étudiant : nom, promo, niveau XP, badges obtenus
  • ☐ Avatar sélectionnable parmi 8 propositions

    • 3.1.2 Catalogue des jeux

  • ☐ Vue grille des jeux disponibles (assignés par le prof)
  • ☐ Chaque jeu affiche : titre, matière, durée, niveau, nb joueurs
  • ☐ Statut : À faire / En cours / Terminé / Verrouillé
  • ☐ Barre de progression globale (% du catalogue complété)

    • 3.1.3 Expérience de jeu

  • ☐ Mode Solo : jouer seul à son rythme
  • ☐ Mode Équipe : jusqu'à 4 équipes sur le même écran
  • ☐ Mode Classe : le prof projette, les étudiants votent sur téléphone
  • ☐ Chronomètre par question
  • ☐ Explication après chaque réponse avec référence au cours
  • ☐ Score calculé avec bonus de vitesse
  • ☐ Badges pour les séries de bonnes réponses

    • 3.1.4 Tableau de bord étudiant

  • ☐ Score total cumulé (XP)
  • ☐ Historique des parties jouées
  • ☐ Taux de réussite par matière
  • ☐ Classement dans la promo
  • ☐ Badges et trophées obtenus


    • 3.2 ESPACE PROFESSEUR


    3.2.1 Authentification

  • ☐ Connexion sécurisée email + mot de passe
  • ☐ Récupération de mot de passe par email
  • ☐ Profil professeur : nom, établissement, matières enseignées

    • 3.2.2 Dashboard principal

  • ☐ Vue d'ensemble : nb étudiants actifs, nb jeux, nb sessions
  • ☐ Graphique d'activité hebdomadaire
  • ☐ Dernières sessions jouées
  • ☐ Alertes : étudiants en difficulté (taux < 40%)
  • ☐ Score moyen de la promo par jeu

    • 3.2.3 Gestion des jeux

  • ☐ Liste de tous les jeux créés
  • ☐ Créer un nouveau jeu (nom, matière, description, durée estimée)
  • ☐ Dupliquer un jeu existant
  • ☐ Archiver / supprimer un jeu
  • ☐ Assigner un jeu à une ou plusieurs promos

    • 3.2.4 Éditeur de questions

  • ☐ Ajouter une question (texte de la question)
  • ☐ Types de questions :
  • QCM (2 à 4 réponses)
  • Vrai / Faux
  • Scénario (mise en situation)
  • Défi Flash (chrono court)
  • ☐ Définir la bonne réponse
  • ☐ Ajouter une explication (affichée après réponse)
  • ☐ Référence au cours (numéro de fiche, chapitre)
  • ☐ Niveau de difficulté : Facile / Moyen / Difficile
  • ☐ Points attribués (auto-calculés selon difficulté)
  • ☐ Temps alloué (en secondes)
  • ☐ Organiser les questions en modules thématiques

    • 3.2.5 Gestion des promotions

  • ☐ Créer une promo (nom, année, code d'accès unique)
  • ☐ Ajouter/supprimer des étudiants
  • ☐ Voir la liste des étudiants inscrits
  • ☐ Assigner des jeux à la promo
  • ☐ Générer un QR code d'accès pour la promo

    • 3.2.6 Gestion des sessions de jeu

  • ☐ Créer une session (jeu + promo + date)
  • ☐ Lancer / mettre en pause / terminer une session
  • ☐ Code session à 6 chiffres pour rejoindre en temps réel
  • ☐ Vue en direct : qui a rejoint, scores en temps réel
  • ☐ Timer global de session

    • 3.2.7 Statistiques & Rapports

  • ☐ Statistiques par jeu :
  • Score moyen / médian / max / min
  • Taux de réussite par question
  • Questions les plus échouées (en rouge)
  • Durée moyenne de la session
  • ☐ Statistiques par étudiant :
  • Historique de toutes les parties
  • Évolution du score dans le temps
  • Points forts et points faibles par thème
  • ☐ Statistiques par promo :
  • Classement de la promo
  • Distribution des scores (graphique)
  • Comparaison entre promos
  • ☐ Export des résultats :
  • CSV (Excel)
  • PDF récapitulatif


    • 3.3 GESTION DU CONTENU


    3.3.1 Bibliothèque de jeux

  • ☐ Jeux privés (visibles uniquement par le créateur)
  • ☐ Jeux partagés (visibles par tous les profs de la plateforme)

    • 5. EXIGENCES NON FONCTIONNELLES


    5.1 Ergonomie

  • Interface intuitive, prise en main < 2 minutes
  • Accessibilité : contraste suffisant, police lisible
  • Mode sombre natif (thème Navy Blue)
  • Responsive sur tous les écrans

    • 5.2 Maintenabilité

  • Code modulaire : chaque jeu est un module indépendant
  • Documentation du code
  • Ajout d'un nouveau jeu sans modifier le code existant
  • Mise à jour des questions sans recompiler l'app

    • 5.3 Scalabilité

  • Architecture supportant 1 à 10 000 utilisateurs simultanés
  • Firebase scale automatiquement
  • Quota gratuit Firebase : 50 000 lectures/jour (largement suffisant)

    10. CRITÈRES D'ACCEPTATION


    L'application est considérée comme livrée si :

  • ☐ Un étudiant peut rejoindre la plateforme avec un code promo
  • ☐ Un étudiant peut jouer à Legal Quest et voir son score sauvegardé
  • ☐ Le professeur peut se connecter avec email/mot de passe
  • ☐ Le professeur voit en temps réel les scores des étudiants
  • ☐ Le professeur peut créer un nouveau jeu avec des questions
  • ☐ Le professeur peut exporter les résultats en CSV
  • ☐ L'application fonctionne sur mobile (Android) et navigateur web
  • ☐ Les données sont sauvegardées même après fermeture de l'app
